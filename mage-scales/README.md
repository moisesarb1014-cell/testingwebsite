# Mage Scales — Agency Website

Single-page static site (HTML/CSS/JS, no build step). Open `index.html` in a browser,
or serve locally with `python3 -m http.server` from this folder.

## Sections
Hero · Portfolio · Services · 3-Step Growth Framework · Testimonials · Meet the Owner · Contact

## Before launch — replace placeholders
- **Portfolio** – project names/descriptions are samples; swap the CSS browser mockups for real screenshots.
- **Testimonials** – placeholder text; add real client quotes.
- **Meet the Owner** – add the owner's name, photo and bio.
- **Contact** – update the email, and connect the form to a service (Formspree, Netlify Forms, etc.). It currently only validates on the front end.
- **Book Intro Call** buttons – point them at your Calendly (or similar) link.
